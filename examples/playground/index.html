Every query pays its own fare.

FareQL prices every GraphQL request by exactly what it asks for and gets it paid over MPP, the open HTTP 402 payment standard. Type a query and watch the meter run, then pay and ride the whole trip.

IN PLAIN WORDS

An API that charges like a taxi meter.

Think of an API as a shop that sells answers. Usually you need an account, an API key and a monthly plan first. With FareQL, every question has its own small price, and anyone (a person, an app or an AI agent) can pay it on the spot.

1

Ask a question

Your app or AI agent asks the API for data, for example "the 20 newest users with their emails".

2

See the exact price

Before anything runs, the API answers with a quote: what it costs and why, field by field. Simple questions are free.

3

Pay cents, get the answer

The payment (a stablecoin on Tempo) goes straight to the API owner. The answer comes back with a receipt. No account, no subscription.

API ownersSell data per question instead of plans. One line in your GraphQL server.
AI agentsPay as they go for exactly the data they use, with a spending limit.
Developersnpm install fareql, mark prices with @price, done.
